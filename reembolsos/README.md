# Reembolsos (app para iPhone)

App web instalable para subir boletas de salud y seguir en qué va cada reembolso.

- **Aquí no hay datos.** Ni nombres, ni montos, ni claves. La app los pide a una web app de Google Apps Script con un enlace secreto que se guarda solo en el teléfono.
- Las fotos y PDF que subes van directo a Google Drive.

## Instalar en el iPhone
1. Abrir `…/analista-electrico/reembolsos/` en **Safari**.
2. Compartir → **Añadir a pantalla de inicio**.
3. Abrir la app desde el ícono y pegar el enlace secreto.
