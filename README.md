# Balance Solar

App web instalable (PWA) que muestra un balance eléctrico y solar mensual.

Este repositorio contiene **solo el diseño** de la app. No contiene datos ni claves:
la app pide los datos a un servicio privado usando un código secreto que se guarda
únicamente en el teléfono de su dueño.

## Instalar en el iPhone
1. Abrir la dirección de la app en **Safari**.
2. Botón Compartir → **Añadir a pantalla de inicio**.
3. Abrir la app desde el ícono y pegar el enlace secreto en Ajustes.
