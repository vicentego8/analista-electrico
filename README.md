# Balance Solar (app para iPhone)

App web instalable que muestra el balance eléctrico y solar de la casa.

- **Los datos no están aquí.** La app los pide a la web app de Google Apps Script ("Balance Electrco") con un enlace secreto que se guarda solo en el teléfono.
- La planilla se llena sola cada mañana (trigger 8 AM que lee la boleta Enel desde Gmail).

## Instalar en el iPhone
1. Abrir la dirección de GitHub Pages en **Safari**.
2. Botón Compartir → **Añadir a pantalla de inicio**.
3. Abrir la app desde el ícono y pegar el enlace secreto en Ajustes.
